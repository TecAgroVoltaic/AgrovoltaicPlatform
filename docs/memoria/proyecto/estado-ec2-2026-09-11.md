## Cómo redesplegar el analizador (desde esta Mac, llave `~/.ssh/visione-ec2`)
```bash
rsync -az -e "ssh -i ~/.ssh/visione-ec2" --exclude .venv --exclude __pycache__ --exclude .env \
  --exclude '*.egg-info' agente-analizador/ ec2-user@52.1.28.77:/home/ec2-user/analizador/agente-analizador/
ssh -i ~/.ssh/visione-ec2 ec2-user@52.1.28.77 \
  'cd /home/ec2-user/analizador && docker-compose -f docker-compose.analizador.yml up -d --build'
```
(El runbook decía `~/aws/visione-key.pem`; la llave real en esta Mac es `~/.ssh/visione-ec2`.)
