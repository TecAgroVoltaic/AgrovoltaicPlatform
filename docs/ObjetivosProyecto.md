## 2. Proyectos asociados

### 2.1 Proyecto 1

Arquitectura multiagente, adaptativa y explicable impulsada por IA para el mapeo y monitorización multidimensional del proceso emprendedor (AEI → MPV → APM).

La contribución principal de la pasantía se vincula con el **Objetivo Específico 2** del proyecto: construir el flujo mínimo funcional de extremo a extremo con agentes y MLOps básicos.

### 2.2 Proyecto 2

AGRIVOLTAIC: Combinación de la tecnología fotovoltaica en entornos agrícolas para mejorar la competitividad de la región Huetar Norte.

La contribución principal de la pasantía se vincula con el objetivo de implementar una plataforma en la nube basada en Machine Learning que soporte la recolección, almacenamiento, visualización y predicción de datos para un sistema agrovoltaico.

---

## 3. Objetivo general de la pasantía

Desarrollar, validar y evaluar un flujo mínimo funcional de extremo a extremo que integre un dashboard inteligente con agentes virtuales basados en IA, capacidades de visualización y predicción de datos agrovoltaicos, mecanismos de explicabilidad y componentes básicos de MLOps, contribuyendo simultáneamente al Proyecto AGRIVOLTAIC y al proyecto de arquitectura multiagente para el monitoreo del proceso emprendedor.

### Objetivos específicos

1. Analizar los requerimientos funcionales y técnicos necesarios para integrar datos agrovoltaicos en una plataforma en la nube con visualización, predicción y soporte mediante agentes virtuales.
2. Diseñar una arquitectura mínima funcional que combine recolección, almacenamiento, procesamiento, visualización y predicción de datos para sistemas agrovoltaicos.
3. Implementar un dashboard inicial que permita visualizar datos relevantes del sistema agrovoltaico y consultar información mediante agentes virtuales con IA.
4. Construir un flujo multiagente básico con herramientas de RAG, web/API, reflexión, feedback, trazabilidad y registro de acciones.
5. Integrar elementos de explicabilidad en la interfaz del dashboard mediante técnicas como LIME o SHAP para apoyar la interpretación de predicciones o alertas críticas.
6. Incorporar componentes básicos de MLOps, incluyendo validación de datos, versionado, evaluación continua, documentación técnica y flujo básico de CI/CD.
7. Validar el prototipo con el equipo investigador en Costa Rica y Alemania, generando recomendaciones para su continuidad dentro de ambos proyectos.
8. Evaluar, mediante un caso de estudio, el desarrollo de los productos generados en ambos proyectos utilizando la plataforma de IA que Isaac está desarrollando como parte de su práctica de especialidad, con el fin de analizar su aplicabilidad, funcionalidad, integración técnica y potencial de escalamiento en contextos reales de investigación.

## 4. Producto integrador esperado

### 4.1 Prototipo funcional de dashboard inteligente para datos agrovoltaicos con agentes virtuales de IA

El producto principal de la pasantía será un prototipo funcional que integre visualización de datos agrovoltaicos, análisis mediante IA, agentes virtuales, explicabilidad, trazabilidad, logging y componentes básicos de MLOps.

- Módulo de visualización de datos agrovoltaicos.
- Módulo de consulta mediante agente virtual.
- Integración inicial con fuentes de datos, archivos, APIs o datos simulados.
- Flujo RAG básico para consulta documental o técnica.
- Módulo de predicción inicial o simulación predictiva.
- Visualización de explicabilidad con SHAP o LIME para casos críticos.
- Registro de interacciones y acciones de agentes.
- Estructura mínima de MLOps para validación, versionado y evaluación continua.
- Documentación técnica y guía de uso.

### 4.2 Producto adicional de evaluación

Como producto complementario, se desarrollará un caso de estudio orientado a evaluar el desarrollo de los productos generados en ambos proyectos mediante la plataforma de IA que Isaac está construyendo como parte de su práctica de especialidad.

## 10. Caso de estudio posterior al regreso a Costa Rica

El tercer mes permitirá consolidar los resultados de la pasantía internacional mediante un caso de estudio orientado a evaluar el desarrollo de ambos productos: el dashboard inteligente agrovoltaico y el flujo multiagente con IA, explicabilidad, logging y MLOps básico.

El caso de estudio utilizará como base la plataforma de IA que Isaac desarrolla como parte de su práctica de especialidad, con el fin de analizar si dicha plataforma permite apoyar, acelerar, documentar o evaluar el desarrollo de productos tecnológicos en proyectos de investigación aplicada.

### 10.1 Componentes mínimos del caso de estudio

- Descripción del contexto de los dos proyectos de investigación.
- Descripción de los dos productos desarrollados durante la pasantía.
- Descripción de la plataforma de IA desarrollada en la práctica de especialidad.
- Criterios de evaluación de los productos.
- Evidencias de desarrollo, pruebas, integración y validación.
- Análisis de resultados, limitaciones y oportunidades de mejora.
- Recomendaciones para escalar los productos dentro de los proyectos.

### 10.2 Criterios sugeridos de evaluación

| Criterio | Descripción | Producto evaluado |
|---|---|---|
| **Funcionalidad** | Grado en que el producto cumple las funciones previstas. | Dashboard agrovoltaico y flujo multiagente. |
| **Integración técnica** | Capacidad de conectar datos, agentes, modelos, APIs, módulos de explicabilidad y repositorio técnico. | Ambos productos. |
| **Usabilidad** | Facilidad de comprensión y uso de la interfaz para usuarios técnicos o investigadores. | Principalmente dashboard. |
| **Explicabilidad** | Capacidad de interpretar resultados, predicciones, alertas o decisiones apoyadas por IA. | Dashboard y flujo multiagente. |
| **Trazabilidad** | Registro de acciones, consultas, decisiones del agente, cambios y eventos relevantes. | Flujo multiagente. |
| **MLOps básico** | Validación de datos, versionado, evaluación continua, documentación y flujo inicial de CI/CD. | Ambos productos. |
| **Escalabilidad** | Potencial de ampliación hacia nuevas variables, sensores, casos de uso o proyectos. | Ambos productos. |
| **Aplicabilidad investigativa** | Utilidad de los productos para apoyar procesos de investigación aplicada y colaboración internacional. | Ambos productos. |
